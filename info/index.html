Welcome to The Briefing Room!

The Briefing Room is a personal project that gathers news from hundreds of sources, uses AI to sort the stories into categories, rank them, and summarize the top ones, and publishes the result here. Every headline links back to its original source, and past editions are kept in the Archive.

Being informed shouldn’t be a second job. A few minutes here is enough to know what’s going on in the world, and where to read more when something deserves your time.

Behind the Scenes

The backend is a n8n workflow that runs on a docker container. It launches every morning and takes about 7 minutes to complete.

The website itself is designed in Webstudio and exported as a static site with client-side code embedded in it. It’s a semi-static site that can’t communicate with a backend, but it still gets daily updates.

The code is written entirely by free-tier Claude. It's responsible for card generation and content manipulation of various components in the headlines section.

Everything in the project uses the zero cost options. The tools and methods were all chosen for their simplicity, efficiency, and ease of use. There are a few API keys on free tiers for tasks like scraping, translation and 2 free llm models (gpt oss 120b, mistral small 4 119b) provided by my University.
