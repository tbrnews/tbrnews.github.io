GitLab has disclosed a critical remote code execution (RCE) flaw, tracked as CVE-2026-90970, in its AI Gateway service that could allow authenticated users with Duo Agent Platform access to execute arbitrary commands on unpatched instances. The vulnerability, stemming from improper input neutralization, affects self-hosted AI Gateway deployments used by GitLab Self-Managed customers, though GitLab-hosted instances are already protected. GitLab has released patches in versions 19.2.4, 19.3.2, and 19.4.1 and urged immediate upgrades to mitigate the risk. This follows last month’s disclosure of a maximum-severity path traversal flaw in GitLab’s core editions that CISA added to its list of actively exploited vulnerabilities. As GitLab is widely used among Fortune 100 companies and other major enterprises, the impact of unpatched flaws could be significant.
